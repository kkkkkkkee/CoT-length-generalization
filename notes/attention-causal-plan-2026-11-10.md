# 注意力集中与规则—状态比例：固定 checkpoint 干预

研究问题：正确规则与当前状态的总attention m，以及正确规则占二者的比例 r，是否分别影响长度泛化？主要终点为完整五槽全链准确率，配对测试每条题的救回/破坏与首次错误位置。

固定28个checkpoint：Phase D dense / soft λ1 / row_tied各4 seed、replicate0；新位置预训练none / learned_abs / sinusoidal / relative的row_tied各4 seed、replicate0。按既定索引选择，不按probe成绩挑选。使用全新面板seed10140001，每模型L4/L16/L64各256条，所有条件共用相同题。各条件跨4个FFN seed求均值和范围，不把每个query当独立模型重复。

每模型50个条件：original及完全相同attention的sham；正确规则权重的25%/50%移到其他predicate；保持rule/state比例将总质量提升到至少.9/.99/1；保持总质量将rule比例设为.25/.5/.75；同时提升到至少.99和比例.5；以及m∈{.5,.9,.99,1}×r∈{.25,.5,.75}完整12格面板。非相关背景的内部比例尽量保持；背景原本全零时明确使用均匀分配。

针对9个主要干预各做3个随机对照。每query选一个可行的随机可见key顶点e_k，用(1-t)a+t e_k使attention L1改变量与目标干预相同。逐query匹配，不截断所请求幅度；记录实际L1和最大匹配误差。它不匹配扰动支持大小，也不是L1球上的均匀采样；随机扰动可能改变m/r，必须一起报告。随机对照函数不读取正确规则位置，只接收目标幅度和可见范围。

全部干预使用真实prefix与真实规则位置，不把答案标签传入权重修改函数，不改变模型参数、FFN或因果mask。记录checkpoint/source/panel hash、全clause/value整链/单步、m/r、熵和L1。保存每条题配对结果，审计sham预测一致、参数前后hash一致、归一化/非负/无未来attention和随机等幅。

结论边界：这是有oracle位置的机制诊断，不是无需额外信息的推理方法。TF整链与同一确定性逐步干预greedy的“整条全正确”事件对应，但本实验没有直接测greedy最终答案的误差恢复；不把它称为自由生成最终答案率。attention干预也会改变FFN混合输入，足够集中仍失败可能涉及权重比例或FFN适配，不自动证明唯一原因。旧初步probe已经有集中/平衡拆分，但随机扰动被donor mass截断，本轮新增长度/质量二维剂量和严格L1随机对照。
