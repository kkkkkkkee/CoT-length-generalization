# 收敛条件探索面板（2026-11-10）

本面板接续上一会话的问题：什么数据结构和约束使训练更容易找到能长度泛化的路由？这是在既有 A/B 之后固定的新探索设计，不冒充预注册确认实验，也不等价于原论文定理的直接复现。

## 已固定的比较

- S5、128 variables；沿用已准入的 local FFN seed 0/1/2/3，按索引选取，未按泛化结果挑选。
- 所有学生从相同 seed 的 local FFN、Q=0 开始；冻结 FFN。
- 每个模型 seed 使用两个独立 L4 数据重复，每次 4096 个抽象题目，第二步 value 真值监督。
- 1000 Adam 更新，batch 128，lr .03。所有处理按 seed/rep 配对数据、batch 次序、测试面板。
- 每 250 步记录独立验证、Q 行残差、匹配分数差、CE 和正则损失；终点独立 TF 1024 题、自由生成 128 题，L2/4/8/16/32/64。
- 6 个 25 步 smoke 后运行 72 个正式探索 run；失败时停止，保留所有失败记录。

| 处理 | Q 参数化 | 正则 | 数据增强 |
|---|---|---|---|
| dense | dense | 无 | 无 |
| soft_0.001 / .01 / .1 / 1 | dense | 行内非对角残差平方均值 × λ | 无 |
| row_tied | 每行独立对角 + 共享非对角 | 无 | 无 |
| rename | dense | 无 | 每次呈现每题独立变量 ID 重命名 |
| rename_soft_0.01 | dense | λ=.01 | 同上 |
| q_l2_0.01 | dense | Q 全元素平方均值 × .01 | 无 |

软结构惩罚严格定义为：

R(Q) = (1/2) Σ_{b∈{43,44}} [1/(n(n−1)) Σ_i Σ_{j≠i} (Q^b_ij − mean_{k≠i} Q^b_ik)^2]。

这是 loss 中的显式正则，不是 AdamW 衰减。普通 Q-L2 对照使用两个 Q 块全部元素平方均值，相同系数不表示优化作用的大小完全相同。R 的零空间仍允许每行具有不同的对角和背景值；它不是全变量置换等变约束。硬 tying 的优化参数和 Adam 状态维度不同，有限 λ 的轨迹不保证等于硬 tying。

变量重命名对一条输入中的所有变量身份一致替换，保留相等关系、逻辑链、动作、状态和监督值。每次呈现重新抽取，因此抽象题/值标签数不变，但变量 ID 组合曝光更多；不能称为完全相同的有效信息预算。独立增强 RNG 不改变 batch 次序。训练保存呈现后的 query-ID 计数。冻结 FFN 本身不保证严格变量置换等变。

## 判别性预测

1. 若软结构惩罚提高泛化，并降低非对角行残差，而普通 Q-L2 无同等效果，则支持去除特定身份偶然关联的解释。
2. 若 dense 重命名即可接近硬 tying，则有限 ID 组合覆盖可能是主要障碍；不说明任何数据增强都足够。
3. 若只有硬 tying 有效，则需区分优化几何、约束强度和有限预算，不能宣布 dense 不可能成功。
4. 若 Q 残差下降但 L64 仍失败，继续检查匹配 margin、正确规则/状态 attention 质量与比例、局部 FFN 的混合分布外行为。
5. 所有结论局限于当前干净标签、S5、L4→长链、1000步协议；不把固定预算性能称为数学收敛。

统计按每个模型 seed 内先平均两个数据重复，再平均四个 seed；保留全部逐 seed/rep 值与相对 dense 的配对差值。测试面板不用于选择停止点、seed 或 λ。
