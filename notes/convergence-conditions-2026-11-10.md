# 从存在泛化解到可学习泛化解：数据结构与约束条件

日期：2026-11-10（北京时间）。依据用户提供的会议版 PDF、现有精读笔记和截至本日已完成的实验；下文页码均指该 PDF 页码。本文是研究备忘录，区分原文已证明结论、可直接推出的有限模型事实，以及尚待证明或检验的猜想。

## 1. 先校正问题的逻辑起点

这篇论文已经超出了“存在一个能长度泛化的参数解”。Theorem 4.1（第 8 页）证明，在指定分布、架构、初始化、学习率尺度和 Algorithm 1 下，梯度训练得到的模型能从 L1/L2 推广到多项式长度。Theorem 5.1（第 10 页）证明另一类动作结构下的递归自训练保证。因此真正待回答的是：**哪些假设负责让训练走向泛化解，哪些可以放宽，以及有限数据、普通 FFN 和 Adam 下用什么较弱条件替代它们。**

需要保留三个区别：

1. **表达性：**假设类中有没有正确算法。
2. **统计可识别性：**训练分布及监督是否能排除同样拟合短题、但长题失败的解。
3. **优化可达性：**指定初始化和更新规则能否在可接受时间内找到所需解。

损失很低只说明有限样本拟合；结构正则改善 OOD 只说明一个训练协议有效；二者都不能单独替代收敛证明。论文中的 loss 是对分布取期望的目标（Definition 3.7，第 8 页），其梯度训练保证也不能直接当作固定 4096 题 minibatch Adam 的有限样本保证。

## 2. 数据为什么能够给出正确的梯度方向

Assumption 3.2（第 6 页）规定变量无放回均匀采样、初态均匀采样、动作有放回均匀采样，中间状态由真实转移递推。这些条件各有作用。

| 条件 | 提供的信号或排除的歧义 | 放宽后需要检查什么 |
|---|---|---|
| 五槽 clause 编码 | 将动作、source variable、当前 state 等角色显式分开 | 编码本身已注入局部结构，不能宣称模型从无结构 token 自行发现全部关系 |
| 变量身份均匀随机，与状态/动作分离 | “变量相等”是稳定的跨题检索线索，具体 ID 关联不稳定 | query ID 与 pair 的覆盖、偏斜分布、有限样本偶然关联 |
| 链中变量不重复 | 当前变量对应唯一下一条规则，目标检索不歧义 | 重复变量是否导致多个可行后继；这不能只当作普通噪声 |
| 动作和初态覆盖 | 为局部运算和不同干扰上下文提供足够辨别信息 | action–state pair 覆盖，动作别名和 fiber 的交叠结构 |
| 正确中间状态、局部一致目标 | 给定当前状态后，下一步标签等于该规则的输出 | 区分“偏离原题但局部一致”与“输入—目标局部冲突” |
| 短链课程与充分局部训练 | 先获得可复用局部运算，再把长上下文问题交给检索 | FFN 是否在注意力混合分布上仍正确，而不只在理想输入上正确 |

原文第 33–34 页的机制不是笼统的“数据更对称所以泛化”：query 变量同时出现在下一条 predicate 的槽 3 与当前 answer 的槽 4，使两个 Q 块的匹配对角项获得有利梯度；还要控制两个目标的相对注意力以及非匹配项。Simply transitive action 中，每个状态对只有一个动作（Assumption 4.1）；S_n 自然作用中同一状态对对应多个动作，FFN 学到的 fiber 共享表示不同，随后的注意力动力学也不同（第 32–35 页）。

**监督位置也是条件。** Algorithm 1（第 28 页）的 simply-transitive attention 阶段使用 L2 两个位置的 value loss 之和。第 34 页分析中，早期第一步梯度先推动 predicate 匹配，随后第二步梯度主导共同增长。Algorithm 2 的 S_n 训练则用第二步 value loss。我们当前 S5 runner 的 `--mode second` 与后者的监督位置相符，但若直接迁移到 C5/C6，不能将仍只监督第二步的实验称为 Algorithm 1 的严格复现。

## 3. 什么约束在限制错误解

原文固定正交 embedding、Q=0 初始化、只训练 Q43/Q44、特殊 FFN、固定偏置和 logit clipping，并分阶段冻结参数（第 6–8、28–29 页）。**C.2 仅限制 token 槽块，保留的块内部仍为完整 dense 矩阵**；作者明确强调这仍是非平凡的学习问题。对角化、row tying 是我们另加的结构先验，不是原文定理的必要条件。

记每个变量匹配块的第 i 行对角为 d_i，非对角均值为 b_i。几种约束的差别如下。

| 约束 | 允许的矩阵 | 主要作用与未解决问题 |
|---|---|---|
| 无结构 dense | 任意 Q | 能表达算法，也能记忆具体 query–key 偶然关联 |
| soft row tying | 在任务 loss 上加行内非对角方差惩罚 | 压制上述关联，但不保证对角大于背景，也不保证两类目标平衡 |
| hard row_tied | Q_ii=d_i，Q_ij=b_i（j≠i） | 去掉行内错误 ID 偏好，仍允许不同 query ID 学到不同参数 |
| diagonal | Q_ij=0（j≠i） | 同时去掉可学习背景；与 row_tied 的容量和优化不同 |
| 完整置换不变的路由核 | Q=aI+b11ᵀ | 所有 query 共享对角/非对角参数，能把已见 ID 的匹配学习传递给未见 query ID |

对于所有变量置换矩阵 P，若要求固定路由核满足 PᵀQP=Q，则 Q 必须形如 aI+b11ᵀ。这可由置换将任意对角位置互换、将任意有序非对角位置互换直接推出。row_tied 的**模型类**在重命名后仍封闭，但一般单个 row_tied 矩阵不满足这个等式，不能称为完整变量置换等变。

而且路由核满足该条件还不足以使整个网络等变：变量 embedding、FFN 输入和变量输出也必须按同一置换变换。我们冻结的普通 MLP 并未硬性满足该性质。因此“变量重命名增强”是一个实际可检验的数据干预，不能未经验证就等同于精确群对称的总体风险。

更具体地，数据分布对变量重命名不变，并不自动推出冻结某个 FFN 后的路由目标满足 L(PᵀQP)=L(Q)：这还需要模型及其固定部分的相容等变性。即使该风险对称成立，也可以存在成组的非对称局部极小点，不能仅凭对称性断言优化得到置换不变 Q。参数群平均 \(\bar Q=\mathbb E_P[P^\top QP]\) 确实得到不变矩阵，但当前 softmax attention、非线性 FFN 与交叉熵的复合目标一般不对 Q 凸，因此不能直接用 Jensen 推出 \(L(\bar Q)\le L(Q)\)。对已对齐输出的预测概率做群平均，在交叉熵下可以用凸性比较风险，但那是概率集成，不等于把 Q 平均，也未必属于同一模型或计算预算。只有在风险及更新规则都等变、从精确不变参数出发、采用精确确定性梯度等额外条件下，才可证明训练轨迹留在不变子空间；这仍未证明它到达所需泛化解。有限批次增强通常只有期望上的对称性。

普通 L2/weight decay 与这些约束也不同：它同时压低正确匹配分数和错误关联。对长上下文，足够大的匹配—背景 margin 可能是需要保留的信号，所以“参数范数更小”不必然更利于长度泛化。

## 4. 可先证明的三个有限模型命题

以下不是论文已有定理；它们是可审查的理论切入点。

### 命题 A：缺少 query 覆盖时，行内约束不能凭空学到缺失行

在当前 attention-only 实现中，Q 通过 query ID 索引行。若某个 ID 从未作为受监督 query 出现，则任务 loss 对其行没有梯度。从 Q=0 开始，普通无动量初始状态的梯度更新/Adam，以及仅对该行内部施加 row-tie 惩罚，都不会使这行产生正确匹配 margin。hard row_tied 仍每个 query 独立，也有同样缺口。

这是针对该参数化、初始化及损失的直接事实，不是所有架构的不可学习定理。完全跨行共享参数、跨 ID 的数据增强或其他耦合正则可以改变结论。可用留出一组 query ID、保持其仍可作为 key 出现的实验验证此区分；否则“没见 query”与“没见任何变量 token”会混淆。

### 命题 B：软惩罚可控制偏离 row_tied 子空间的量，但不足以保证算法

将两块 Q 合写，令 Π 是到 row_tied 线性子空间的正交投影，E=(I−Π)Q。若取 R(Q)=½‖E‖²_F，在梯度流下：

\[
\dot E=-(I-\Pi)\nabla\mathcal L(Q)-\lambda E.
\]

若沿轨迹有 ‖(I−Π)∇L‖_F≤G，则直接积分得到

\[
\|E(t)\|_F\le e^{-\lambda t}\|E(0)\|_F+
\frac{G}{\lambda}(1-e^{-\lambda t}).
\]

这给出“正则强度控制错误方向幅度”的明确目标。若实际实现对两块的所有非对角元素取均值，则 R=‖E‖²/[2n(n−1)]，收缩系数变为 λ/[n(n−1)]，不能跨变量规模直接比较同一个 λ。离散步长、Adam 预条件和随机梯度都需要另行分析。

更关键的是，E≈0 的集合也包含 Q=0、错误符号的匹配 margin、以及规则/状态严重失衡的解。还必须证明在这个集合附近，任务梯度推动 margin 增长并进入 FFN 的正确工作区域。**控制残差是收敛分析的一部分，不是整个证明。**

### 命题 C：检索误差与局部计算稳健性可组合为长度保证

对于正确前缀、无重复变量的 row_tied 模型，当前 query 为 i、前面有 t 条旧 answer 时，正确规则和当前 answer 的联合质量精确为

\[
m_i(L,t)=\frac{e^{d_{43,i}}+e^{d_{44,i}}}
{e^{d_{43,i}}+e^{d_{44,i}}+(L-1)e^{b_{43,i}}+t e^{b_{44,i}}}.
\]

该式已在上一轮小模型直接计算中核验。若背景个数为 O(L)，保持高目标质量通常要求有效 margin 随 log L 增长；但联合质量高仍可能只检索到两种必要信息中的一种。

一个完整的充分条件应该同时要求：目标质量足够高；正确规则与当前 state 的相对比例落在可用区间；冻结 FFN 对该混合邻域有正分类 margin。先证明这些条件下每一步五槽都正确，再对 rollout 归纳，才能得到整链保证。若只能控制每一步的条件错误概率≤δ，则可用 union bound 给出整链失败概率≤Lδ，无需假设步骤独立。当前经验性 m≥0.95“容量”没有包括 FFN 稳健性，不能直接当作准确率定理。

## 5. 下一轮实验怎样区分解释

最紧凑的主轴是同一合格 FFN、Q=0、相同训练题和 minibatch 顺序下，比较 dense、soft row-tie 强度扫描、hard row_tied。保存原始 CE、加权正则、Q 残差、各 query 的 margin 分布、两类目标质量/比例以及 L8/L16/L64 的整链率。至少有多模型 seed 和独立数据重复，并保留全部 seed，不能按 L64 表现选“代表”模型。

| 可区分的现象 | 支持的解释 | 仍不能得出的结论 |
|---|---|---|
| λ 增大时残差降低且 OOD 改善，CE 仍可拟合 | 行内错误关联是有限协议中的一个瓶颈 | 单调剂量响应本身不是一般收敛证明 |
| 残差已很小但 OOD 仍失败 | margin、两目标平衡、FFN 稳健性或训练不足仍重要 | 不能以“正则无效”概括所有原因 |
| 在线变量重命名让 dense 接近 hard tie | 有限样本身份关联可能被数据干预削弱 | 增强也改变了有效样本数和噪声记忆，需相同呈现预算对照 |
| 留出 query ID 时 row_tied 失败，而全局共享核成功 | 跨 query 参数共享承担了未见身份迁移 | 不能把总体优势都归因于更好的优化器 |
| 等预算短题训练与长度课程相同 | 当前成功不依赖长度增长本身 | 不能否认自训练节省新真值标签的价值 |
| 在更长优化后低 LR 也拟合污染并退化 | 早期低 LR 优势可能主要来自延迟记忆 | 固定 1000 步排名不代表收敛后排名 |

数据侧的最小正交对照是固定题库与每次呈现一致重命名变量：同一题所有 predicate/answer 中的同一变量必须一致替换，action/state 不变。若使用噪声，必须预先声明噪声绑定在语义题还是变量化后的样本上；两者对应不同的记忆难度。谓词顺序重排另测位置依赖，不能替代变量身份增强。比较不同代数结构时，C5、aliasC5 和 S5 需要分别准入的局部模型；aliasC5 有 120 个动作 token 但仅 5 个实际变换，不是 120 元 simply-transitive action。

## 6. 已有证据能支持到哪里

大规模 A/B 已完成 502/502 任务。Phase A 的 8 模型 seed×3 数据重复中，干净真值的 row_tied L8/L16/L64 整链率为 99.98%/99.80%/16.05%，dense 为 77.29%/14.78%/0%；L64 成功集中于部分 seed，不能宣称稳定收敛到长程泛化解。20% 局部一致前缀改动接近干净训练，而局部冲突前缀或错误目标造成明显下降。这支持“匹配结构”和“局部标签一致性”值得分别干预。

上一轮更长训练中，row_tied 的自教师课程、真值课程、持续 L2 最终都达到约 99.80% L64，提示优化预算本身足以改变结论。那轮与当前 A/B 初始化/总训练预算不同，不能合并成一个不依赖条件的性能数字。

因此当前最可信的工作假设是：**覆盖充分且局部一致的数据让正确检索有可辨别梯度；结构约束压制有限样本中的错误身份关联；足够的优化还要建立能抵抗上下文稀释的 margin，并保持局部 FFN 可用。** “足以”需要以上三部分的联合证明或有边界的实验验证，不能只由某一个正则项推出。
