# 双头端到端复现实验：第二轮

日期：2026-11-12。目的：补齐原文附录 A 的实证复现基线，定位早期结果与原文的差距。本文在正式运行前写入；不是原文理论定理的严格复现。

## 已确认的问题

原文公开设置：C6/S5、五槽 clause、单层 decoder、双头、NoPE、Adam 1e-4、300 epochs、L5 基础训练及 S5 的 L5→10→20→40 递归自训练。原文报告自由生成后所有 answer value 正确的概率。未充分公开宽度、数据量、batch、残差/LayerNorm 等设置，继续明确区分公开设置和我们的实现选择。

早期三个 seeds 的最终训练 CE：C6 约 1.86e-8–1.90e-8，S5 约 4.60e-8–4.76e-8；value 槽 CE 也很低。不能先验归因于训练标签尚未拟合；需要检验有限题库泛化、增加更新及推理分数尺度。详见 [基线审计](replication-baseline-audit-2026-11-12.json)。2026-11-12 再次检查 arXiv:2511.07378 摘要页，未发现 GitHub/GitLab 链接；这不是穷尽的官方代码检索。

## 共同模型与数据

沿用 `src/model.py` 的双头端到端模型，不改成机制实验的两个块模型：256 变量；共享可训练 64 维 token embedding；五槽拼接宽 320；2 头；标准 Q/K/V 和输出投影；pre-LN 残差；共享 GELU FFN 宽 1280；无位置编码、dropout 和 weight decay。Adam 默认 betas/epsilon，lr=1e-4，batch=128，所有参数联合训练，所有 CoT 步骤、五槽平均交叉熵。

数据遵循无放回变量、均匀动作与初态的 LEGO 分布。报告整链准确率，同时记录逐槽 CE、变量/状态错误及注意力诊断。各个“epoch”均对应 8192 条序列、64 次更新，含义不混用。

## 第一部分：题库与训练预算，12 个正式运行

C6/S5 × fixed/fresh × seeds 0/1/2。每个运行从头训练 900 epochs（57,600 更新），保存 300、900 两个预定终点。300 epochs 是与原公开轮数对应的参考；900 是明确标记的三倍预算扩展。

- fixed：重复同一组 8192 题。
- fresh：每 epoch 新生成 8192 题。epoch 1 与 fixed 完全相同，以后采用独立、可复现的种子。
- 同任务同 seed 的 fixed/fresh 初始参数相同。模型与学习率保持一致。
- 两策略在每个终点匹配更新、序列和标签呈现量；独立样本数不同，这正是干预。
- 每 50 epochs 保存可恢复状态并记录训练数据子集及独立 L5/L10/L20 验证表现。训练子集指标仅作为拟合诊断，不能称全训练集评测；每 epoch 的优化 CE 覆盖全部本轮数据。
- 不依赖训练损失门槛提前停止，不根据长链测试挑选 checkpoint。低 CE 但长链不佳也保留。

## 验证选择与测试隔离

验证种子 121200001，每长度再加长度；测试种子 121900001，每长度再加长度。均不同于此前面板。验证 L5/L10/L20，每长度 256 题；所有候选均实际完整 greedy 生成。测试 L5/10/20/40/80/160，每长度 512 题，TF 与 greedy 使用同一整组样本。

主结果始终使用默认 attention logits 乘数 α=1。额外恢复分析在验证集比较 α∈{0.5,1,2,4}，按跨三个 seeds、三个长度的自由生成 value 整链均值，选择每种条件/终点的一组 α。并列优先离 1 最近的 log 尺度，再取较小值。默认与选择后的结果分别记录，不把温度恢复算成默认复现成功。α 不用于生成课程伪标签。

全部基线选择文件落盘后才执行新的长链测试。S5 后续母模型的数据策略，由 900-epoch 基线在验证 L5/L10/L20、α=1 的跨 seed 均值选择，精确并列选择 fixed。各 seed 不独立挑不同设置。所有未选条件仍公开测试结果。母模型固定用 900 epochs，因此后续课程属于扩展预算复现，而非声称完全沿用原文 300-epoch 起点。

## 第二部分：S5 三分支，27 个正式训练阶段

由选定数据策略的三个 S5 母模型分别分叉：

1. **self**：L10→20→40；用各自上一阶段教师完整 greedy 生成 8192 条轨迹，全部保留；真值仅用于审计。
2. **truth**：相同长度、同 seed/stage 与 self 使用完全相同逻辑题，使用真值轨迹。
3. **continue_L5**：每阶段新生成 8192 条 L5 真值题，始终保持短链。

每阶段都固定本轮题库，300 epochs、19,200 更新、lr=1e-4，重置 Adam；各分支都采用相同重置规则。即使母模型使用 fresh，课程阶段也固定本轮题库，这是显式设计选择；因此不能把基线 fresh 的收益自动归给课程。

课程分支匹配更新数和序列呈现量，但长题每次包含更多 value 标签和计算量，**不声称等标签或等 FLOPs**。self/truth 的题目在第一阶段完全配对，后续仍配对外部题目，但教师/学生因历史训练分支不同而不同。

每次生成伪标签记录全部五槽/全部 value 轨迹正确率、逐步与最终值正确率；不按真实标签过滤，也不按教师质量删除 seed 或停止分支。每阶段保存全部结果；固定最终阶段为主终点，阶段间曲线为次要分析。各阶段所有分支的温度选择文件在该阶段测试前落盘。后续训练不读取测试结果。

## 判据与解释

主要考察：C6 默认尺度下是否保持长链高准确率，以及 S5 自训练是否改善到接近该水平、是否超出等更新的短链训练。

本项目将“三 seed 平均 L160 greedy value 整链 ≥99%，且每 seed ≥95%”用作预先声明的操作性高成功判据；这不是从原文推导出的数学阈值。报告均值、各 seed、每 seed 的二项比例 Wilson 区间；512 题的 100% 也不代表总体零错误。只有三个 seeds，不能宣称广泛稳定性。

新测试面板用于最终评估当前固定方案；由于此前同分布 L160 已被用于提出这次方案，这是探索后的新面板验证，不是从未接触过该任务的完全盲测。未知原超参数仍限制逐数值复现的解释。
