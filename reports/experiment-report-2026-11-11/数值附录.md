## 表 03

2.3 dense、软约束、hard row_tied 到底是什么

| 名称 | 定义 | 两块 Q 的参数数 | 作用与限制 |
|---|---|---:|---|
| dense | 每个 \(Q_{ij}\) 独立可训练 | 32,768 | 可学变量相等，也可记忆具体 ID 配对 |
| soft row tying | 保留 dense 参数，在损失中惩罚每行非对角差异 | 32,768 | 压制不匹配 ID 的偶然偏好，但不强制完全相同 |
| hard row_tied | \(Q_{ii}=d_i\)，\(Q_{ij}=b_i\;(j\ne i)\) | 512 | 同一 query 的所有不匹配 key 共用背景参数 |
| diagonal | 非对角恒为零，只训练对角 | 256 | 去掉错误配对自由度，也去掉可学习背景 |
| rename | 每次呈现一致重命名一题中的变量 ID | 不变 | 保留逻辑关系，改变 ID 组合曝光 |
| Q-L2 | 惩罚全部 Q 元素的平方均值 | 不变 | 同时压低错误关联和正确匹配分数 |

## 表 04

2.4 指标与统计单位

| 指标 | 定义 | 用途 |
|---|---|---|
| TF 完整整链 | 每一步使用正确历史，所有步骤、全部五槽都预测正确 | 本报告默认主指标 |
| TF value 整链 | 所有步骤的状态值正确，不要求其他槽都正确 | 辅助指标，可能高于完整整链 |
| greedy 完整整链 | 把模型生成的全部五槽反馈，整条生成轨迹全对 | 实际自由生成验证 |
| greedy 最终 value | 只判断自由生成最后一个状态值 | 不代表中间推理轨迹正确 |
| 正确规则 strict top-1 | 正确规则分数严格高于其他规则；并列不计成功 | 检索排序诊断 |
| 相关质量 \(m\) | 正确规则和当前状态位置的注意力之和 | 集中程度，不等同于低熵 |
| 规则占比 \(r\) | 正确规则注意力 / 两个正确位置的总质量 | 必要信息之间的平衡 |
